# expense-tracker
an expense tracker built using python and SQL
## Features
- add expense with amount, category, date and note
- View all expenses in formatted table
- see total amount spent
- Filter expenses by date rane

## Tech stack
-python
-SQLite (using python's built in 'sqlite3')

## How to run
1. Clone this repository
2. open a terminal
3. Run : python database.py
